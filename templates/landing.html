How it works

Up and running in minutes

No complex setup. Add a machine, run the agent, watch the stats roll in.

1

Create a free account

Register in seconds — no credit card, no BS. Your first 3 machines are always free.

2

Add a machine & get a token

Click + Machine, fill in a label and host. Then grab a 🔑 Token from the manage panel.

3

Run the agent

On the monitored machine:
pip install psutil websockets
python3 agent.py --token <token>
Stats appear live within seconds.

Architecture

The agent connects outbound — works behind NAT and firewalls, no port forwarding needed.
